3. **Reasoning before the cause** (`odd/tasks/report-field-order.md`, `4585c0c`, `2b4143f`, `41b9965`, closed at `d044eae`).
   - Cloud F3 fell to 10/15 with line citations. In 3 of the 5 misses the summary named the right cause and the fields did not, because the fields came first and the model chose a cause before reasoning.
   - The order is now `summary, evidence, rootCauseService, rootCauseCategory, confidence`.
   - The longer reasoning then ran past 500 characters, so 7 of 15 reports were invalid, and a length hint did not help. Code now cuts a summary over 500 characters instead of rejecting the report.
   - Results: cloud F3 15/15, F1 5/5, F2 5/5 (about $0.34 over four runs). Local F1 0/3, F2 3/3, F3 0/3, with every report valid (9/9).
4. **A change column in the dossier** (`odd/tasks/dossier-change-column.md`, `46139df`, reverted by `7b8a4cf`).
   - Local F3 showed granite reading the previous window's rows as the incident's. The gateway-mock 429s were 6 in the previous window and 0 in the incident, yet two of three reports named gateway-mock. It also read past the `ConnectException` (0 then 6) and the `:9999` URL.
   - Each count table got a `change` column, incident minus previous, computed by code. It is arithmetic only, with no threshold, so ADR-011 holds.
   - Local results were the same: F1 0/3, F2 3/3, F3 0/3. With `D23 | ... 429 ... | 6 | 0 | -6 |` in the dossier, the summary still spoke of "a surge of ... 429". The column was reverted.

## Decisions and why

- **600 s local deadlines rather than smaller prompts.** The reading speed of this CPU (about 11 tokens/s) sets the floor, and the 45-minute budget still holds.
- **Line numbers rather than looser quote matching** (ADR-013). Looser matching would let through evidence the outputs do not hold. A number is an exact choice, and code copies the text.
- **Reasoning first.** A model writes left to right, so fields written earlier condition the later ones. The answer belongs after the reasoning.
- **Cut, not reject, a long summary.** The model cannot count characters well enough to land under a hard limit. The cut costs nothing that is checked: the cause, category and evidence are untouched.
- **Option A (a change column) rather than a thresholded "Changes" section.** A threshold would have needed an ADR superseding part of ADR-011 ("No judgments, hints, anomaly markers or thresholds"). The column was reverted because it did not help, and it took the stress dossier's token ceiling from 5,500 to 5,700.

## What we learned

- On the local model, how the dossier presents the evidence is no longer the lever: granite misreads the window direction even when it is written out.
- Local F1 was 2/3 with quotes and is 0/3 since line citations and the new order; it always names payment-service. Whether the citations cost it is not settled.
- `ReportCheck` checks that a cited line exists, not that it supports the item's `why`: local F3 cited D17, a success row, for a `ConnectException`.
