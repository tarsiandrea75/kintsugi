# Journal — 2026-10-07 — Session 05: local-only project, fault injector, M1 complete

## What happened
- **Local-only.** The human decided: no posts, no pushes. The vision now says the project stays local, with full `git bundle` backups and their sha256 kept outside the laptop. The roadmap posts, the hosted CI and the public-repo assumption are gone. A full audit checked git state, links, ports and the runbook leakage. A test clone made from the bundle passed every test suite.
- **The fault injector reopened M1.** `docs/vision.md:148` was not done. Without recorded truth, the M2 check cannot be scored.
- **fault-injector** ([feature](../../odd/tasks/fault-injector.md), [ADR-009](../adr/ADR-009-fault-injector-docker-control.md)): option A, chosen by the human. F1 and F2 go through the gateway admin API. F3 and F4 are real compose redeploys driven through the Docker socket, so they leave deploy evidence.
  - The truth lives in its own `faults` database.
  - Every service moved to a non-superuser `lab_app` role.
  - The injector is invisible in Loki and Prometheus.
  - All four verify scripts inject through it and assert the truth and the isolation.
- **Reviews** were run on every range. Real design flaws were caught before or while coding:
  - the superuser bypass of `REVOKE CONNECT`;
  - an injection left half-restored that did not block a new one;
  - an unbounded `--wait`;
  - a restore race;
  - orphaned processes;
  - CLI images pinned only by tag;
  - credentials leaking into the compose child process;
  - a silent `DOCKER_GID` default that hid a real bug.

## Decisions and why
- **No posts, no pushes.** This is the human's choice. The vision is the single source of truth, so it was updated in the same change.
- **Option A: the Docker socket plus compose recreates.** F3 stays "wrong config via env", as the vision says. A redeploy leaves real evidence for the future `getDeployments` tool. The risk is root-equivalent access through the socket, the same accepted for Alloy, and every port is bound to loopback.
- **Non-superuser roles everywhere.** A superuser ignores `REVOKE CONNECT`. Truth isolation is only real if no service role and no agent role is a superuser.
- **Refuse to inject without recording the truth.** An incident with no ground truth cannot be scored.
- **One active injection, enforced by a constant-expression partial unique index.** An index on the status column would allow one row per status.
- **Fail loudly on configuration.** `DOCKER_GID` is required, the compose file must exist at startup, and the repo is mounted with `create_host_path: false`.
