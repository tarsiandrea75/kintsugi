## Decisions and why

- **Levels are annotations, not retries** (the human's choice). Only L0 retries, and L1 drops an item as it did before. The SHEETS graph rules no longer retry, because the retry fed topology hints back into the prompt and steered the model. SHEETS is not on the measured path. This closes ADR-014's open question.
- **L3 = at least one cited fact of the claimed cause changed**, not every item: citing a caller is legitimate evidence.
- **Logs stay `NOT_COMPARED`** (the human's choice). Logs have no previous window, so calling them changed would claim more than the code checked. T6 and T8 ran before the freeze to measure the cost. On both dev sets no correct answer rests on log lines alone: RE2-OB has 1, which also fails L2, and the lab has 0. So no previous log window is added.
- **The 0.5 s latency floor was removed** (the human's choice, after T6). It is R-DOWN's diagnostic threshold, and it marked a 10–25× rise as unchanged. The change is post hoc on the 30 dev cases that motivated it, and ADR-028 Decision 5 says so. Config 0's rules are untouched.
- **The lab dev cloud run** was approved by the human: about $0.02, with a $0.10 bound.
- **The regeneration test now regenerates a committed `policy.tsv`** (`1931cb9`). The lab dev result is the first one whose inputs carry the policy columns.
