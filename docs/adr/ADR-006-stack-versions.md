# ADR-006: Stack versions and runtime defaults

## Status

Accepted

## Date

2026-10-05

## Context

ADR-001 chose Java with Spring Boot and Spring AI but deferred exact versions. The first module, `agent/`, was generated from Spring Initializr and exercised against a local Ollama model, so the versions and runtime defaults are now known and verified. The number is 006 because the vision reserves ADR-002 to ADR-005 for other decisions.

## Decision

Versions:

- **Java 21** (LTS). Corretto 21.0.9 is installed locally. Java 25 LTS also exists; the author chose 21.
- **Spring Boot 4.1.1**, as generated by Spring Initializr.
- **Spring AI 2.0.1**, imported through its BOM. The 2.1.0-M1 preview is not used.
- **Maven** through the Maven Wrapper: Maven 3.9.16, wrapper 3.3.4. A local Maven install is optional.
- **JUnit 6.0.3**, managed by Spring Boot.
- **Ollama >= 0.4.6** (local install: 0.34.4).

Runtime defaults in `agent/src/main/resources/application.yaml`:

- `spring.ai.retry.max-attempts: 0`. The default is 10 retries with exponential backoff up to 180 s. A refused connection on localhost means the server is down, so retrying only delays the error.
- `spring.http.clients.read-timeout: 5m`. A cap for CPU inference with an 8B model, not an expectation. `connect-timeout: 2s`.
- `spring.ai.ollama.chat.temperature: 0`, for repeatable tool-calling behavior.
- `spring.ai.ollama.chat.num-ctx: 8192`. The default 2048 is too small once tool schemas are included.
- Properties use the Spring AI 2.0 form `spring.ai.ollama.chat.*`; the `chat.options.*` form is deprecated.

Model: `granite4.1:8b` is in use. The final choice is pending the tool-calling smoke test (change B) and will be recorded in ADR-003.

## Alternatives considered

- **Gradle**: no advantage for this scope; Maven matches the author's experience and the Initializr defaults.
- **Spring AI 1.1.x with Spring Boot 3.5**: more mature, but a previous generation and a later migration cost.
- **Java 25 LTS**: newer, but 21 is sufficient and widely supported.

## Consequences

### Positive

- Pinned versions isolate API churn: Spring AI 2.0 differs from 1.x in property names and `ChatModel` option handling.
- The wrapper makes builds reproducible without a local Maven.
- Fast failure when Ollama is down.

### Negative

- Upgrading any pinned version requires a new ADR or a superseding one.
- The model choice is still provisional.
- Spring Boot 4 and Spring AI 2 have less community documentation than the previous generation.
